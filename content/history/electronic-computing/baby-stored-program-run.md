## An experimental memory system becomes a working machine

Manchester's account dates a successful stored-program run of the Small-Scale Experimental Machine, or Baby, to 21 June 1948. It identifies Williams, Kilburn and Tootill and describes the machine as a test bed for the Williams-Kilburn storage tube.

## A specific organizational milestone

Holding instructions electronically changes how a machine can obtain its next operation. This property is distinct from using transistors: the Baby belonged to a tube-based implementation context. An experimental run is also distinct from a later production system or widespread deployment.

## Scope of the attribution

This entry follows the university's documented run date without adopting an unrestricted claim to the invention of every computer or every stored-program idea. The [electronic-computing chapter](/history/electronic-computing/) places it beside relays, vacuum tubes, semiconductor devices and integrated processors. That chapter's invented accumulator program is a teaching example, not a translation of this run's actual instructions.
