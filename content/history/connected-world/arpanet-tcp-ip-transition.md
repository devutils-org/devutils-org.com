## Coordinate a protocol change

The Internet Society's participant account describes ARPANET's transition from NCP to TCP/IP on 1 January 1983. Hosts had to convert to continue communicating through the intended protocols. The authors describe planning and implementation work over several years, not a network appearing fully formed on that date.

## Distinguish the network from its applications

An existing packet network changing host protocols is not the same event as inventing the World Wide Web. Nor does it date all prior packet research, every deployment of TCP/IP or universal public Internet access.

## Evidence and perspective

The source is a retrospective account by participants, with strengths and limits associated with that involvement. This event records the community-specific transition date; it does not independently verify every host's operational state that day.
