REPRODUCIBLE INVESTIGATIONS

            
Trace as code.

            
Prototype a measurement in the shell, then keep it in a session file. YAML, JSON and TOML describe the same requests. The program is part of the request: launching it makes it both the target and the clock.

            Browse the sessions ↗
          

          
# omn -f examples/mem-rss-run.yml
name: resident memory of a launched program
requests:
  - label: rss
    source: mem.rss
    target:
      launch: [python3, -c, "..."]
    mode: poll@100ms
    emit: [timeline, summary]
    keys: [task, cgroup]
