REPRODUCIBLE INVESTIGATIONS

            
Trace as code.

            
Prototype a measurement in the shell, then keep it in a session file. YAML, JSON and TOML describe the same requests. The program is part of the request: launching it makes it both the target and the clock.

            Browse the sessions 
          

          
# omn -f examples/mem-rss-run.yml
name: resident memory of a launched program
requests:
  - label: rss
    source: mem.rss
    target:
      launch: [python3, -c, "..."]
    mode: poll@100ms
    emit: [timeline, summary]
    keys: [task, cgroup]

        

      


      

        

          

            
TESTED WITH DISTROPROOF / OCTOBER 2026

            
Different kernels.
Explicit limits.

          

          
The installed releases were tested on 16 distro images and 5 variants, spanning Linux 4.15 to 7.2, glibc and musl. The same binary listed 36 sources usable on Ubuntu 18.04 and 96 on Fedora — with a reason for each refusal.

        

        

          

            
Availability checked against reality.

            
The campaign found 16 defects: 9 in the tool and 7 in its tests. Initially, 158 source runs were listed usable but refused at start. After the fixes, none did. Every refusal reason agreed with envprobe’s independent reading of the same guest across all 21 targets.

            Explore the distroproof case study →
          

          

            
Features, beyond version numbers.

            
Real probes catch Debian’s perf policy, BPF maps charged to memlock on 5.10, lockdown restrictions and Alpine’s missing function tracer. RHEL backports are detected as features rather than ruled out by kernel age.

          

          

            
Two release archives.

            
The glibc archive targets glibc 2.17+. Alpine has a native musl archive with a static engine and a musl preload shim. NVIDIA sources are unavailable in the static build because they need dynamic library loading.

          

          

            
What remains open.

            
Reference comparisons against distro-packaged perf, bpftrace and other witnesses ran on six distributions; some still differ or skip. Fedora opensnoop and Rocky 9 lock contention remain open. This campaign does not cover aarch64, containers or NixOS.
