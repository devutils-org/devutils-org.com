# Figures expansion — 29 October 2026

118 profiles were added to the existing Shannon profile, for 119 published English profiles. The English and French directories display the same collection; the French directory explicitly labels untranslated profiles.

All 99 distinct people or attributed authors named in the existing history-of-computing planning document have a profile, including separately named members of groups. Repeated milestones for the same person share a profile. That document was used as a coverage checklist, not as historical evidence: its first-inventor claims and dates were not copied into the profiles. Ancient and medieval additions extend the collection through Greek, Chinese, Indian, Arabic and Latin reasoning traditions. This is an expandable computing-history directory, not a claim to catalogue every person in intellectual history.

Each new profile has a contribution, context and limits, a connection to a published chapter, and an assessment of its cited contribution passage. Assessment is by Codex; independent human review remains pending. Most profiles are concise introductions with one cited source, not full biographies or independently corroborated priority studies. Source titles identify the actual author or publisher.

## Verification

- All 119 profiles load through the content and assessment validators and have an assigned reading period.
- All 99 people in the planning checklist are present (groups expanded and duplicates removed).
- npm test: 74 tests pass, including rendered internal links and assessment validation.
- npm run verify:content: 33 reproducible example-check groups pass. These checks do not establish historical accuracy.
- npm run build: all generated documents, links, Pagefind indexes and SEO checks pass.
- Chrome at 1440 and 390 pixels: English and French directories show all profiles without JavaScript, working period anchors and no horizontal overflow.
- With JavaScript: query, no results, category filter and reset pass in both languages; empty period sections are hidden.
- All profile routes return HTTP 200 and include sources and verification records.
